## 实现

磁盘布局为超级块、inode 位图、inode 区、数据位图、数据区。mkfs 默认创建课程要求的 5 GiB 数据区及 65536 个 inode，使用稀疏文件与 64 位偏移；已有镜像拒绝覆盖，修正框架 block_read 误写问题。

VirtIO 队列使用睡眠等待、中断唤醒及单调 16 位完成计数。内核页表增加 MMIO 映射，NULL 页表查询表示当前内核页表，支持内核栈 DMA 地址转换。PLIC 保留原 UART 通路。

缓存槽默认 16384 个（课程常量，数据容量上限实际为 64 MiB），数据页按需分配，内核页不足时回收非活跃缓存。命中移动到活跃头部；缺失选择非活跃尾部并置于活跃尾部；最后一个引用归还后移入非活跃头部。有效标记与睡眠锁避免并发读到未初始化数据。所有槽被持有时返回失败，不递归等待自己。

位图扫描覆盖多个块与末尾不足整块的有效位，分配与释放同步写回。调试句柄必须属于当前进程持有的缓存；无效地址、重复归还、递归获取均返回错误。退出先释放所持缓冲区，再进入 Lab6 原有退出/回收流程。

## 并发磁盘中断回归

VirtIO 改为先确认中断，再读取完成队列，防止清掉读取队列后新到达的完成通知。修复后的本分支通过单核一轮和双核三轮四进程并发写盘，每轮 512 次块写入，并在缓存回收后及 QEMU 退出后核对磁盘完整数据。原 Lab7 的单/双核、默认缓存和位图边界套件也已重新通过。
